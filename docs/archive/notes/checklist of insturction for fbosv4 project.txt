# FBOS V4 – ENGINEERING RULEBOOK (3Rcore+)

## PURPOSE

This is the permanent engineering rulebook.

Every new engineer or AI agent must follow these rules before writing any code.

========================================================

1. SINGLE REPOSITORY RULE
   ========================================================

ONLY production repository:

fbos-v1

RPOSFIN/fbosv4

* helper repositories
